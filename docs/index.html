Embed Images in Markdown

Just drag and drop an image into your Markdown.
No more scattered image files — everything lives in a single .md file.

Get it on VS Code Marketplace View on GitHub

Features

🖱️

Just drag and drop

Hold Shift and drop an image onto the editor — that's it.

📦

Single-file, self-contained

Images are converted to DataURLs and appended to the end of the file, preventing image files from scattering around your project.

🖼️

Common formats supported

Works with png / jpeg / jpg / gif / webp (uppercase extensions too).

🗂️

Explorer drag & drop too

Also works when dragging from the VS Code Explorer view, and supports pasting into an inactive editor pane.

How it works

  1. Open a Markdown file.
  2. Hold Shift and drag an image file onto the editor.
  3. A reference link is inserted at the drop position, and the image body (DataURL) is appended to the end of the file.

Before you start

⚠️ Required setting
The setting markdown.editor.drop.enabled must be set to false for this to work.
Known limitations
  • If you drag and drop multiple files at once, only one gets pasted.
  • Requires VS Code 1.74.0 or higher.
